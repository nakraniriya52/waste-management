# Waste Collection Management System

A Tkinter desktop application for recording and analyzing waste collection data.

## Requirements covered
- Python functions and data structures
- CSV file handling for persistent storage
- 4 user-defined modules: main.py, data_manager.py, analysis.py, charts.py
- NumPy arrays and Pandas DataFrames/Series
- Tkinter GUI
- Matplotlib visualizations
- Input validation and exception handling
- Documentation and automated validation tests

## Visualizations
1. **Category Bar Chart** - total waste by waste category.
2. **Location Bar Chart** - total waste by location.
3. **Waste Over Time Graph** - line graph of daily waste collection.

## Run
pip install -r requirements.txt
python main.py

## Test
python -m unittest test_app.py
